## Windows-Port 0.5 (pre-release)

Unofficial Windows desktop port of **Zangetsu** (original app by Spyou, GPL-3.0).

### 🔧 Fixed
- **Manga extensions could not be installed (0.4).** Two causes: the manga engine takes ~10 s to start and the first installs hit it too early, and the engine could not fetch its own extension list from GitHub. Installs now wait for the engine and send the already-downloaded extension file straight to it.
- **Cloudflare verification window (light novels).** It now closes as soon as the site's page has really loaded (or when you press *Continue*), instead of waiting for one specific cookie that some sites never set. It also uses its own WebView2 profile folder.
- Cloudflare check pages that arrive as a normal "200" are now recognised too.

### ⚠️ Known limits
- Light-novel sources behind Cloudflare may still fail; this is the part I am least sure about. Manga filters/settings and Cloudflare-protected manga sources are not supported yet.
- Not tested by me on every source — please report problems with `zangetsu.log` (and `manga-engine\engine.log`).

🤖 **AI disclosure:** developed with the help of AI (Claude, by Anthropic) as a coding assistant. I direct the work, test every build on my own PC, and decide what ships.
