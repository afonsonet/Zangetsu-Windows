## Windows-Port 0.3 (pre-release)

Unofficial Windows desktop port of **Zangetsu** (original app by Spyou, GPL-3.0).

### 🆕 New
- **Experimental Cloudflare support for light-novel sources.** A small bundled helper (`cf-helper/cfhelper.exe`) sends requests with a Chrome-like TLS fingerprint, and a WebView2 window lets you pass the "verify you are human" check when a source asks for it.
- Network activity for novel sources is now written to `zangetsu.log` (host + status only) to help diagnose problems.

### 🔧 Fixed
- **0.2 stored its data in a new folder** (settings, login and installed sources looked reset). 0.3 goes back to the original data folder, so your data from 0.1 is picked up again.

### ⚠️ Notes
- Cloudflare support is untested on real sources; it may not work everywhere yet.
- Manga/Mihon extensions and the Providers/Sources menus are unchanged.
