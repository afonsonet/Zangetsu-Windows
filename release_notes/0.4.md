## Windows-Port 0.4 (pre-release)

Unofficial Windows desktop port of **Zangetsu** (original app by Spyou, GPL-3.0).

### 🆕 New
- **Manga on Windows (experimental).** Mihon/Keiyoushi extensions now run through a bundled engine ([Suwayomi-Server](https://github.com/Suwayomi/Suwayomi-Server), MPL-2.0, with its own Java runtime). The **Mihon** row is back in *Providers → Manga & Novel* with install, browse, search, chapters and the reader.
- The download is much bigger (~200 MB more) because of that engine. Extract the **whole folder** — the `manga-engine` folder must stay next to `Zangetsu.exe`.

### ⚠️ Known limits
- Light-novel (LN) sources still don't work reliably — the Cloudflare work from 0.3 is not finished.
- Manga: no per-source filters, no source settings, and Cloudflare-protected manga sources are not supported yet. CloudStream and Aniyomi (anime extensions) remain Android-only.
- First start of the engine takes a few seconds; the first install of an extension can need a retry.
- Untested on real sources by me beyond a CI smoke test — please report problems with `zangetsu.log` and `manga-engine\engine.log`.

🤖 **AI disclosure:** developed with the help of AI (Claude, by Anthropic) as a coding assistant. I direct the work, test every build on my own PC, and decide what ships.
