🖥️ Zangetsu Windows Port — Alpha v0.2 (Early Preview)

Still an early alpha, so expect rough edges. Test at your own risk!

🤖 **AI disclosure:** the changes in this release were made *with the help of AI* (Claude, by Anthropic) — I describe what I want, the AI writes the code, and I test it on my PC. They were not hand-written by me. This is an unofficial community port, based on the open-source Zangetsu app by Spyou (GPL-3.0).

✅ **What's new in v0.2:**

- **Real app identity:** the app now uses the Zangetsu icon and is named **Zangetsu** (`Zangetsu.exe`, window title, file properties) instead of the default Flutter icon / `watch_app`.
- **Keyboard shortcuts in the player:**
  - `Space` — play / pause
  - `←` / `→` — skip back / forward 10 seconds (hold to keep skipping)
  - `F` or `F11` — toggle fullscreen
  - `Esc` — exit fullscreen
- **True fullscreen:** a new fullscreen button in the player's top bar. The video now covers the whole screen and hides the taskbar (before, it was only a maximized window).

✅ **Still working (from v0.1):** desktop UI navigation, account sync, standard video playback.

⚠️ **Known quirks / not available yet:**

- Cloudflare-protected light novel sources still fail on desktop.
- CloudStream, Aniyomi and Mihon extensions are Android-only and don't load on Windows yet.
- Unsigned build: Windows SmartScreen may warn — "More info" → "Run anyway".

📦 **How to use:** download `Zangetsu-Windows.zip`, extract the *whole* folder, then run `Zangetsu.exe`. Drop any crash logs or weird behavior in the channel so we can track it down.
